# Conventions for this repo

Hackathon project (EXL × UCD 2026, Challenge 03). Context and defaults are in
`README.md` — read it first.

## Scope discipline

This is a 5-hour build. Favor a small, honest, end-to-end slice over breadth.
Never present an unverified reconciliation result as reconciled — if a legacy
baseline is a reference re-implementation rather than the original engine
(true for all SAS jobs, see README), every report and doc must say so plainly.

## Data

Synthetic only, generated by `data/generate_synthetic_data.py` with a fixed seed.
Never add real/personal data to this repo.

## Code

- Python 3.12, PySpark 3.5.x -- except CI's `test` job, which runs on 3.11:
  pyspark 3.5.3's `toPandas()` still imports the stdlib `distutils` module,
  which Python 3.12 removed. `ruff` for lint/format (runs via pre-commit).
- One legacy job -> one PySpark job -> one test file -> one reconciliation report,
  named consistently by job slug, e.g. `legacy/claims_monthly.sql` ->
  `pyspark_jobs/claims_monthly.py` -> `tests/test_claims_monthly.py` ->
  `reconciliation/reports/claims_monthly.md`.
- Agent scripts in `agents/` call `claude -p` with a prompt file and validate the
  output against an explicit schema/contract before writing it to disk — never
  trust agent output blindly into the repo.

## Tests

`pytest` from repo root (`pytest.ini` sets `testpaths = tests`). Coverage via
`pytest-cov`, Cobertura XML output for SonarQube.

## Commits / MRs

Small, logical commits ending `Refs #<issue-iid>`. One story per branch
(`<iid>-<slug>`), one MR per branch, `main` is protected.
