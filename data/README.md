# Synthetic data

Generated by `generate_synthetic_data.py`, seed `42`. Synthetic only -- no real
or personal data. Run `python data/generate_synthetic_data.py` from the repo
root to (re)produce `policies.csv`, `claims.csv`, `premiums.csv` here; the
output is byte-identical on every run.

## `policies.csv`

| Column | Type | Notes |
|---|---|---|
| `policy_id` | string | `POL######`, primary key |
| `customer_id` | string | `CUST######`, many-to-one with policies |
| `product_line` | string | Motor, Home, Life, Travel, Commercial |
| `start_date` | date (ISO) | policy inception |
| `end_date` | date (ISO) | policy expiry |
| `sum_insured` | float | GBP/EUR, not currency-qualified (synthetic) |
| `region` | string | ~2% blank, deliberately, to exercise null-handling |
| `status` | string | Active, Lapsed, Cancelled |

## `claims.csv`

| Column | Type | Notes |
|---|---|---|
| `claim_id` | string | `CLM#######`, primary key |
| `policy_id` | string | foreign key to `policies.csv` |
| `incident_date` | date (ISO) | when the loss occurred |
| `claim_date` | date (ISO) | when the claim was filed (0-30 days after incident) |
| `claim_type` | string | depends on the policy's `product_line` |
| `claim_amount` | float | capped at the policy's `sum_insured` |
| `status` | string | Open, Approved, Rejected, Paid |

0-4 claims per policy (50% of policies have none), weighted toward fewer claims.

## `premiums.csv`

| Column | Type | Notes |
|---|---|---|
| `premium_id` | string | `PRM#######`, primary key |
| `policy_id` | string | foreign key to `policies.csv` |
| `period_start` / `period_end` | date (ISO) | billing period covered |
| `payment_frequency` | string | Monthly or Annual |
| `premium_amount` | float | one installment |
| `collected_date` | date (ISO) | 0-5 days after `period_start` |

One or more rows per policy, split into Monthly or Annual installments across
the policy's term.
